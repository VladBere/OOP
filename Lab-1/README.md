## Предметна область — спорт

Консольна програма-реєстр спортсменів спортивного клубу. Основний клас — `Athlete` (спортсмен),
перелічення `SportType` (вид спорту) реалізоване в окремому файлі.

| Характеристика | Поле | Тип | Обмеження (перевіряються в `Program.cs`) |
|---|---|---|---|
| Ім'я | `name` | `string` | 2–20 символів, лише латинські літери, слова через пробіл або `-` |
| Дата народження | `birthDate` | `DateTime` | формат `dd.MM.yyyy`, не раніше 01.01.1950, вік не менше 10 років |
| Вид спорту | `sport` | `SportType` (enum) | лише значення з переліку |
| Вага, кг | `weight` | `double` | 30–200 |
| Кількість медалей | `medals` | `int` | 0–500 |
| Професіонал | `isProfessional` | `bool` | `y` / `n` |
| Енергія | `energy` (private) | `int` | 0–100, змінюється лише методами класу |
| Години тренувань | `trainingHours` (private) | `int` | змінюється лише методами класу |

Поведінка класу: `Train(hours)`, `Rest(hours)`, `CanCompete()`, `Compete(opponentRating)`,
`GetRating()`, `GetAge()`, `GetEnergy()`, `GetTrainingHours()`.

## Меню програми

```
1 - Add athlete            (вручну або автоматично, не більше N об'єктів)
2 - Show all athletes      (таблиця з нумерацією)
3 - Find athlete           (за ім'ям або за видом спорту)
4 - Demonstrate behavior   (підменю з усіма public-методами)
5 - Delete athlete         (за номером у таблиці або за видом спорту)
0 - Exit
```
